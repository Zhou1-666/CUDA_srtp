# 一般带宽 (2m+1) 对角系统的 PaScaL-TDMA 推广：结构与通信通式

> 状态: 理论推导 + 数值验证 (m=1..4, 机器精度)。验证脚本: `mband_general.js`。

## 1. 问题设定

考虑带宽 m 的 (2m+1) 对角带状系统:

```
sum_{k=-m}^{m} a_j^(k) x_{j+k} = b_j,   j = 0..L-1
```

线长 L = P·Nrow 被切分为 P 个连续子域 (每 rank 一个, Nrow 行)。目标是
**两级分布式求解**: 每个 rank 先做本地消元把线压缩为少量"接口未知量",
再用全局缩约系统耦合各 rank, 求解后回带。

## 2. 推广方案: 接口未知量 = 2m

**定义 (接口未知量)**。子域 r 的接口未知量为其**两端各 m 个点**:

```
{x_r0, ..., x_{r,m-1}} ∪ {x_{r,Nrow-m}, ..., x_{r,Nrow-1}}   (共 2m 个)
```

理由: 带宽为 m 时, 子域 r 的前 m 行方程引用子域 r-1 的最后 m 个点
(物理接口耦合), 后 m 行引用子域 r+1 的前 m 个点。因此:

- **每个子域恰好有 2m 个点跨越子域边界参与全局耦合**;
- 每子域贡献 **2m 条边界方程** (前 m 行 + 后 m 行);
- **全局缩约系统规模 = 2mP × 2mP**。

内点 (行 m..Nrow-m-1) 经消元表达为 2m 个接口未知量的仿射函数。

**特例对照**: m=1 (三对角) → 2 接口未知量 {x_0, x_{N-1}}, 缩约系统 2P×2P
(原论文); m=2 (五对角) → 4 接口未知量, 缩约系统 4P×4P (已验证的移植)。

## 3. 缩约系统的带结构与槽位格式

**定理 1 (带结构)**。缩约系统为 **2mP × 2mP** 带状矩阵, 下带宽与上带宽均为
**2m-1**:

```
缩约带宽 = (2m-1, 2m-1)
```

证明思路: 每条边界方程引用自身子域的 2m 个接口未知量 + 相邻子域 m 个。
在"每 rank 块 (top m, bottom m)"列排序下, 顶端方程最右可达自身 bottom 未知量
(块内偏移 2m-1), 底端方程最左可达自身 top 未知量 (偏移 -(2m-1))。

**定义 (统一槽位格式)**。每条边界方程用 **(4m-1) 个带槽 + 1 个 RHS = 4m 槽**
的定长格式表示:

```
[L_{2m-1} ... L_1, D, U_1 ... U_{2m-1}, RHS]
```

**特例对照**: m=1 → 每方程 [L,D,U,RHS] 4 槽 (三对角); m=2 → 8 槽
(与五对角移植的 `[L3,L2,L1,D,U1,U2,U3,RHS]` 一致)。

## 4. 恒等对角槽与结构零槽

**定理 2 (对角归一)**。每条边界方程归一化 (除以自身未知量系数) 后, **对角槽
恒等于 1**。因此对角槽无需传输, 组装时由解包核填回 1。

**定理 3 (结构零槽)**。按方程在 rank 块内的位置 e ∈ {0..2m-1} (0..m-1 为顶端,
m..2m-1 为底端), 结构上恒为零的槽位为:

| 方程位置 e | 恒零槽位 (相对对角偏移) |
|---|---|
| 顶端 e (0 ≤ e ≤ m-1) | L 侧: `-(2m-1)..-(m+1)` (m-1 个); U 侧: `+(2m-e)..+(2m-1)` (e 个) |
| 底端 e (m ≤ e ≤ 2m-1) | U 侧: `+(m+1)..+(2m-1)` (m-1 个); L 侧: `-(2m-1)..-(e+1)` (2m-1-e 个) |

**每线结构零槽总数 = 3m(m-1)**。

**特例对照 (m=2)**: 顶端 e=0: `{-3}`; 顶端 e=1: `{-3,+3}`; 底端 e=2: `{-3,+3}`;
底端 e=3: `{+3}` —— 与五对角移植的 rd0..rd3 槽位**完全一致** (rd0 L3=0,
rd1 L3=U3=0, rd2 L3=U3=0, rd3 U3=0)。

## 5. 通信量公式

每线每 rank 的缩约数据 (双精度个数):

| 策略 | 每线通信量 | m=2 | m=4 |
|---|---|---|---|
| 传输全部 4m 槽 | `8m²` | 32 | 128 |
| **只省对角** (当前实现) | `8m² − 2m` | **28** | 120 |
| 省对角 + 结构零槽 (下界) | **`5m² + m`** | 22 | 84 |

**推论**: 相对"只省对角", 同时利用结构零槽可再省 `3m(m-1)` 个槽。
对 m=2 (五对角): 28 → **22** (−21%), 即当前移植仍有进一步的通信优化空间。

**渐近**: 通信量以 **O(m²)** 增长 (缩约数据每线 ∝ 方程数 2m × 每方程槽 4m)。

## 6. 数值验证 (m=1..6)

验证脚本 `mband_general.js` 用**通用 m 缩减** (接口未知量作边界条件, 内点稠密
消元), 对 m=1..6, P∈{1,2,3,4}, 多种子随机对角占优系统:

- **解正确性**: 216 组配置, 与全局稠密直解**最差误差 6.7e-16** (机器精度);
- **结构**: 带宽 (2m-1,2m-1)、对角=1、结构零槽 3m(m-1)、通信下界 5m²+m
  全部与数值统计一致 (m=1..6 均 ✓)。

递推式脚本 `mband_recurrence.js` 用**显式消元递推** (第 9 节公式) 重新实现缩约:

- 递推式 vs 稠密缩减的边界方程**最大差 2.2e-16**;
- 递推式完整解 vs 精确解**最大差 6.7e-16** (m=1..6)。

这确认了显式递推公式 (§9) 与稠密缩减在机器精度下等价, 通式对任意 m 成立。

## 7. 显式消元递推式 (一般 m)

设切片行 j 的系数为 `a_k^{(j)}` (k=-m..m, 即 x_{j+k} 的系数), 对角 `a_0^{(j)}`,
RHS `b_j`。**内点**指行 j ∈ [m, Nrow-m-1], **左接口** {x_0..x_{m-1}},
**右接口** {x_{Nrow-m}..x_{Nrow-1}}。

### 7.1 前向扫 (fwd)

每个内点 j 表达为
```
x_j = Σ_{k=0}^{m-1} P_k^(j) x_k + Σ_{l=1}^{m} Q_l^(j) x_{j+l} + T^(j)
```
**种子 (j=m)**: 行 m 直接解 x_m:
```
P_k = -a_k / a_0,  Q_l = -a_{m+l} / a_0,  T = b_m / a_0      (k,l=0..m-1)
```
**递推 (j>m)**: 对 i=m-1..0 计算 x_{j-m+i} 的"已消解"形式
(只耦合左接口 + x_j..x_{j+m}): `\bar P_k^{(i)}, \bar Q_u^{(i)} (u=0..m), \bar T^{(i)}`。
- 若 j-m+i < m (左接口未知量本身): `\bar P_p^{(i)} = δ_{p,j-m+i}`, 其余 0;
- 否则 (用 fwd[j-m+i] = {P,Q,T} 的 Q 链合成):
```
\bar P_k^{(i)} = P_k + Σ_{l: t<j} Q_l · \bar P_k^{(t)},    t = j-m+i+l
\bar Q_u^{(i)} = Q_u(直接落在 x_{j+u}) + Σ_{l: t<j} Q_l · \bar Q_u^{(t)}
\bar T^{(i)}   = T + Σ_{l: t<j} Q_l · \bar T^{(t)}
```
合并进行 j:
```
den = a_0 + Σ_{i=0}^{m-1} a_{i-m} · \bar Q_0^{(i)}
P_k^(j) = -[ Σ_i a_{i-m} \bar P_k^{(i)} ] / den
Q_u^(j) = -[ a_u + Σ_i a_{i-m} \bar Q_u^{(i)} ] / den     (u=1..m)
T^(j)   = [ b_j - Σ_i a_{i-m} \bar T^{(i)} ] / den
```
其中 `a_{i-m}` 为行 j 中 x_{j-m+i} 的系数。

### 7.2 后向扫 (fin)

**锚点 j=Nrow-m-1**: `P = fwd.P`, `R_r = fwd.Q_r`, `T = fwd.T` (右耦合即右接口)。
**递推 (j 从 Nrow-m-2 降到 m)**: 代 x_{j+l+1} 的最终形式:
```
P_k^(j) = fwd.P_k + Σ_l Q_l · P_k^(j+l+1)          (j+l+1 内点时)
R_r^(j) = Σ_l Q_l · R_r^(j+l+1) + Σ_{l: j+l+1 ≥ Nrow-m} Q_l · δ_{r, j+l+1-(Nrow-m)}
T^(j)   = fwd.T + Σ_l Q_l · T^(j+l+1)
```

### 7.3 边界方程 (2m 条)

行 j∈[0,m-1]∪[Nrow-m,Nrow-1] 的原方程, 内点引用用 fin 代入, 跨切片引用
归入 prev/next, 归一化使对角=1。与 §4 槽位格式一致。

## 8. 定理证明

**定理 1 (接口未知量 = 2m)**。带宽 m 使切片前 m 行方程引用上一切片最后 m 点,
后 m 行引用下一切片前 m 点 (共 2m 个跨边界点); 内点行 (m..Nrow-m-1) 只引用
片内点, 故可本地消元。缩约系统因此为 **2mP × 2mP**。□

**定理 2 (带宽 (2m-1, 2m-1))**。在每 rank 块 `[top m, bottom m]` 列排序下:
顶端方程最右耦合到自身 bottom 未知量 (块内偏移至多 2m-1); 底端方程最左耦合到
自身 top (偏移 -(2m-1))。跨 rank: 顶端→prev bottom (偏移 -m), 底端→next top
(偏移 +m)。故带宽恰为 (2m-1, 2m-1)。□

**定理 3 (对角=1)**。每条边界方程按自身未知量系数归一化; 对非奇异 (对角占优)
系统该系数非零, 归一后对角槽恒为 1。□

**定理 4 (结构零槽 = 3m(m-1))**。按方程位 e∈{0..2m-1} (顶端 0..m-1, 底端 m..2m-1),
数值统计 (m=1..6) 给出的恒零槽 (相对对角偏移) 为:
```
顶端 e : L 侧 {-(2m-1)..-(m+1)} (m-1 个) + U 侧 {+(2m-e)..+(2m-1)} (e 个)
底端 e : U 侧 {+(m+1)..+(2m-1)} (m-1 个) + L 侧 {-(2m-1)..-(e+1)} (2m-1-e 个)
```
理由: 顶端方程行 j<m 最左引用为 x_{j-m} (prev 接口, 偏移恰 -m), 更左的
偏移 -(m+1)..-(2m-1) 结构为零; 底端对称。计数:
```
Σ_{e=0}^{m-1}[(m-1)+e] + Σ_{e=m}^{2m-1}[(m-1)+(2m-1-e)] = 3m(m-1)
```
□ (每方程具体零槽由 m=1..6 数值确认。)

**定理 5 (通信下界)**。每线 2m 方程 × 4m 槽 = 8m²。省对角 (2m) 后为 8m²-2m;
再省结构零槽 (3m(m-1)) 后须传
```
8m² - 2m - 3m(m-1) = 5m² + m
```
□

## 9. 对论文的意义

1. **统一理论**: 把 PaScaL-TDMA 从三对角 (m=1) 推广到任意带宽 m, 给出了
   缩约系统规模 (2mP)、带宽 (2m-1)、槽位格式 (4m)、通信下界 (5m²+m)
   的封闭公式 —— 这是现有三对角论文没有的一般化结果。
2. **结构零槽刻画**: 首次 (据我们所知) 明确刻画了分布式带状缩约系统的
   结构零槽模式 (定理 3), 并据此给出通信下界。
3. **工程启示**: 对已实现的五对角求解器, 通信可从 28 进一步降到 22
   (省 6 个结构零槽), 且可位级无损 (组装填回)。
