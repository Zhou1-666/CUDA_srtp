# 五对角活动上下文

普通编码从本页进入。本页只维护研究边界、技术约束和读取路径；任务状态、排程、授权与下一动作读取 [[../../meta/task-queue]]，具体缺口读取 [[../../meta/task-blocker-register]]。

## 研究与实现边界

- 研究对象是 CUDA Fortran + MPI 分布式五对角线性求解器；独立应用 demo 不代表完整 CFD 软件。
- 三对角代码冻结为参考基线；只有共享缺陷、构建/API 兼容、上游核验和发布回归可以修改。算法、优化或论文工作先读 [[../reference/pascal-tdma-2.1-to-penta-transfer]]。
- 一般半带宽 `m` 的模型验证与五对角 CUDA 实现分开；不将模型公式、相邻论文性能或候选设计当作实际 GPU 结果。
- 修改目标候选前核对实际源码、测试与构建指纹；提交、冻结、验证通过和采用是不同事项，具体验收遵循 [[../testing/source-change-validation-sop]]。

## 技术约束

- API 要求 `Nrow >= 5`、`Nsys >= nprocs >= 1`，不支持空分区；保留线程数、communicator/rank/size 及生命周期的拒绝用例。
- setup 用 64 位临时量预检；CUDA 热循环和传统 MPI count/displacement 仍受默认 32 位整数上限约束，超限须在分配或启动 kernel 前拒绝。见 [[../methods/index-width-contract]]。
- `RHS` 和部分系数会被原位覆盖；调用方须明确 [[../systems/data-ownership-and-lifetime|所有权与生命周期]]。
- 28/22 前向固定布局的映射及适用条件见 [[../methods/28-to-22-slot-map]]；槽位计数不能替代实际通信字节或通用性能证据。
- 没有独立真值不宣称正确，没有同精度实测不宣称更快；单 GPU 多 rank 不能证明多 GPU 扩展性。数值阈值和适用门禁以 [[../testing/source-change-validation-sop]]、[[../testing/test-matrix]] 为准。

## 每个任务的最小读取包

1. 根目录 [AGENTS.md](../../../../AGENTS.md) 和本页。
2. [[../../meta/task-queue]] 中已授权的一项任务、[[../../meta/task-blocker-register]] 中对应条目。
3. 按 [[../../meta/context-routing]] 选择一张方法、测试或性能页；修改前核对 [[../../meta/change-impact-map]]。
4. 用 `rg` 定位目标函数、调用点及对应验证入口，再读必要片段。

任务交接按 [[../../meta/task-handoff-protocol]]；单次运行/排障写入对应 `outputs/validation/` 回执及 `raw/` 原件，里程碑写 compile-log。任务状态变化时更新 queue/必要 blocker 条目，本页不追加交接状态段。
