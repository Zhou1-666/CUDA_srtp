# 单任务完成—复验—下一任务协议记录

- 用户要求：每完成一个任务，给出下一个任务，并说明如何验证上一个任务的正确性。
- 决策：稳定强制规则写入根 `AGENTS.md`，完整模板写入 `knowledge/meta/task-handoff-protocol.md`，暂不创建正式 Skill。
- 原因：P0 和 28→22 闭环尚未完成，当前命令与状态转换仍可能调整；过早建立 Skill 会固化未验证流程。
- 执行要求：每次交接必须包含状态、改动文件、已执行验证、用户复验步骤、预期结果、未覆盖范围和唯一下一任务。
- Skill 门槛：P0 目标环境复现、统一入口用于至少两个真实任务、完成一次 28→22 实现—验证—实验闭环。
