# TASK-019 一般 `m` 公式模型独立审阅

## 结论

模型独立复算支持以下限定公式：在 `m>=1`、`P>=1`、`Nrow>=2m+1`，内点块可逆且
边界归一化主系数非零时，每 rank 保留 `2m` 个接口未知量，全局缩约维数为
`2mP`；按每 rank `[top m,bottom m]` 排序的通用结构半带宽为 `2m-1`；固定带状
打包中局部性强制零槽为 `3m(m-1)`，删除归一化对角与这些零槽后、仍包含 RHS 的
每线载荷为 `5m²+m`。

本审阅不支持把 `5m²+m` 称为任意通信编码的绝对下界，也不支持“首次”“最优”、
任意带宽 Fortran/CUDA 已实现或性能外推。TASK-019 应转为 `review`，等待非原推导者
人工签字和投稿前数据库更新检索。

## 独立复算

对块内方程位置 `e=0..2m-1`，自身块列产生偏移区间
`[-e,2m-1-e]`。顶端方程 `e<m` 只额外连接上一 rank，跨块偏移为
`[-m,-e-1]`；底端方程 `e>=m` 只额外连接下一 rank，跨块偏移为
`[2m-e,m]`。因此所有允许位置均落在 `[-(2m-1),2m-1]`，且顶端第 0 行与
底端最后一行分别达到上下包络。

固定包络的补集给出：

- 顶端 `e`：左侧 `m-1` 个恒零，加右侧 `e` 个恒零；
- 底端 `e`：右侧 `m-1` 个恒零，加左侧 `2m-1-e` 个恒零。

求和为：

`sum_{e=0}^{m-1}[(m-1)+e] + sum_{e=m}^{2m-1}[(m-1)+(2m-1-e)] = 3m(m-1)`。

固定格式共有 `2m × 4m = 8m²` 槽；省去 `2m` 个归一化对角和
`3m(m-1)` 个结构恒零后得到 `5m²+m`。这是特定打包合同的计数，不是信息论下界。

## 发现并修正的问题

1. 理论页把偏移系数 `a_d` 和数组下标混用。种子现明确为
   `P_k=-a_{k-m}/a_0`、`Q_l=-a_l/a_0`。
2. 原结构统计把各样本零槽集合取并集；这会把偶然数值零误判为结构零。现改为
   对同一方程位跨所有样本取交集，并加入瞬时零的回归用例。
3. `5m²+m` 原称“通信下界”过强，现收紧为“固定布局结构裁剪后的槽位数”。
