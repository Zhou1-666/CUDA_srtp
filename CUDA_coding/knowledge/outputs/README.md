# outputs：LLM 查询与派生产物层

一次问答、临时报告、图表、Marp 幻灯片或分析结果先进入这里，而不是直接写入规范 Wiki。

推荐子目录：

```text
outputs/
├─ inbox/       # 新生成，等待判断是否归档
├─ queries/     # 可复查的问答记录
├─ reports/     # 阶段报告
└─ visuals/     # 图、表、幻灯片
```

## 归档规则

每份输出必须说明：问题、读取页面、使用 source IDs、结论、未知项和是否值得回编译。

只有满足以下任一条件才编译回 Wiki：

- 形成可复用概念或代码/公式映射；
- 解决一个开放问题；
- 发现并修正矛盾；
- 产生可重复实验或调试规则；
- 更新论文主张的证据状态。

普通聊天、重复摘要和无来源猜测不归档。输出不能作为自身的原始证据；需要回到 `raw` 来源或新增来源。
