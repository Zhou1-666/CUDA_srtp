# outputs：LLM 查询与派生产物层

一次问答、计划、评审、设计、验证或分析结果先进入这里，而不是直接写入规范 Wiki。

推荐子目录：

```text
outputs/
├─ validation/  # 任务验证回执、分析与对应原件
├─ plans/       # 已归档的执行计划与任务合同
├─ reviews/     # 来源、实现或主张的审查结果
├─ designs/     # 有界设计稿与处置方案
├─ inbox/       # 新生成、待判断是否归档或回编译的材料
└─ queries/     # 可复查的问答记录
```

## 归档规则

每份输出必须说明：问题、读取页面、使用 source IDs、结论、未知项和是否值得回编译。

只有满足以下任一条件才编译回 Wiki：

- 形成可复用概念或代码/公式映射；
- 解决一个开放问题；
- 发现并修正矛盾；
- 产生可重复实验或调试规则；
- 更新论文主张的证据状态。

普通聊天、重复摘要和无来源猜测不归档。输出不能作为自身的原始证据；需要回到 `raw` 来源或新增来源。
