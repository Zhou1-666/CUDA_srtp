# EXP-000：现有基线盘点

## 假设

现有源码与历史实验足以支持“局部加固后优化”，但不足以支持发布级正确性或多 GPU 性能主张。

## 历史性能摘要

历史环境为 RTX 4060 Laptop 8GB + WSL2、NVHPC 24.1、OpenMPI 4.1.7a1、host staging。实验组相对仓库参考组约快 `2.6–4.7×`，但 `np=1→2/4` 为负扩展，因此不能外推为多 GPU scaling。

## 异常与限制

- 两个模块对未初始化 request 调用 `MPI_WAITALL`；
- 报告中的 28→18 已纠正为理论支持的 28→22；
- 无 Git 快照和明确 LICENSE；
- 历史二进制不能替代当前干净构建。

## 结论

数学和 benchmark 基础值得复用，但所有历史性能数字只标记为开发基线。下一实验应记录 P0 修复后的干净构建、单/双 rank 回归和 28 槽 baseline。
