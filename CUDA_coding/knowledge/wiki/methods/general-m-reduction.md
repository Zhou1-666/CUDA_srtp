# 一般半带宽 m 的 PaScaL 缩约

## 已有结论

对 `(2m+1)` 对角系统，每个 rank 取两端各 `m` 个接口未知量：

- 每 rank 接口数：`2m`；
- 全局缩约规模：`2mP × 2mP`；
- 缩约上下半带宽：`2m-1`；
- 完整固定格式：每方程 `4m` 槽（含 RHS）；
- 只省恒等对角：每线 `8m²-2m`；
- 再省结构零：固定带状打包每线 `5m²+m`；
- 结构恒零总数：`3m(m-1)`。

## 证据等级

- `m=1..6` 稠密缩减与全局直解：216 组最坏误差约 `6.7e-16`；
- 显式递推与稠密缩减：108 组边界方程最大差约 `2.2e-16`；
- 独立组合审计不调用原缩减/递推代码，在 `m=1..64` 上验证逐行偏移、结构零计数和固定布局槽位公式；
- 冻结审阅版本的结构统计采用跨全部样本的零槽交集，而非把任一次数值零并入结构零；相关源码修改属于独立 C 批，本次文档集成不声明主树工具已采用该修正；
- Fortran/CUDA 生产实现只有 `m=2`；
- [签字前模型审阅](../../outputs/reviews/TASK-019-20260824-general-m-model-audit.md)记录递推种子下标修正；[周一涵 2026-08-24 人工回执](../../outputs/reviews/TASK-019-20260824-human-review-zhouyihan.md)接受该冻结版本，人工复核缺口已关闭，仅投稿前数据库更新检索仍未完成。回执的电子确认形式与身份核验限制保持，不等于本轮重跑数学或 GPU 验证。

因此本页仍是 `reviewed` 而不是 `verified`，论文不能把一般公式写成任意带宽 GPU 软件已实现，也不能把 `5m²+m` 称为任意编码的绝对通信下界。

适用条件为 `m>=1`、`P>=1`、`Nrow>=2m+1`，内点块可逆且边界归一化主系数非零。
`2m-1` 是通用结构包络；特殊系数可使实际带宽更小。`5m²+m` 是 rank 统一、
固定带状槽位、包含 RHS、删除归一化对角和局部性强制零槽后的载荷计数；首尾 rank
或其他编码可能进一步减少载荷。

## 实现边界

一般实现需要参数化：接口提取、局部递推、结构槽位映射、缩约带状求解和回带。不能只把数组尺寸中的 `4`/`8` 替换为表达式；当前五对角 S1 使用专门的标量递推和原位存储约定。

## 论文使用

可以作为统一理论和 28→22 动机；“首次”“最优”“绝对下界”等强措辞须在人工复核和相关工作检索后决定。真实性能结论只能来自已实现的 `m=2`。
