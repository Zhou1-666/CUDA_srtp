# ADR-001：优化现有五对角实现，不重搭完整软件

## 决策

保留现有 PaScaL 三/五对角算法、独立验证和 benchmark，先局部加固 P0 正确性、构建、许可与回归，再实施 28→22 通信裁剪。SRTP 和论文对象明确为分布式带状求解器核心模块，并增加最小 Poisson/Helmholtz 集成；不在两个月内从零重搭完整 CFD 软件。

## 证据

- 已有 CUDA Fortran + MPI 源码、示例、HPC 和 benchmark；
- 五对角独立验证 72 组达到机器精度量级；
- 28 槽通信模型 756 组无失败；
- 一般 `m=1..6` 结构和递推已有数值验证；
- 历史 CSV 有复用价值，但只来自单 GPU 多 rank；
- 存在未初始化 MPI request、参数/错误检查不足、许可不清和无 Git 快照等问题。

量化审计为 `68/100`，支持“局部重构后优化”。

## 被否决方案

- 直接在现有实现上堆性能优化：P0 会污染性能结论；
- 从零重搭完整 CFD：范围过大，丢失已有算法和证据；
- 只写理论不做 Fortran/HPC：不能支持软件和性能论文。

## 代价与回退

前两周新功能较少，需要目标 NVHPC/MPI 环境和许可梳理。若 G0/G1 后仍无法验证现有 Fortran，则冻结旧版，只重搭 `m=2` 最小链路，仍不扩张为完整 CFD。

## 复审触发

- P0 修复后仍无法干净构建；
- 五对角 Fortran 无法通过独立真值；
- 导师要求严格恢复原 FFT–GMG 全范围；
- 真实多 GPU 结果否定核心性能假设。
