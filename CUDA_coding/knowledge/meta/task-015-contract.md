# TASK-015 数值稳定性矩阵族与主元失败合同

## 单一目标

为当前无主元交换的五对角 28 槽求解器定义并验证数值适用域：正常、弱占优、跨尺度和受控近奇异输入报告残差与前向误差；无法安全继续的零/近零主元以确定的数值失败码拒绝，不传播 NaN/Inf。

## 允许修改

- `src/PaScaL_TDMA_cuda_penta.f90` 中与数值主元检测直接相关的状态、检查和错误消息；
- 独立 Node 数值矩阵族检查；
- 专属 CUDA Fortran 验证程序、构建目标和运行脚本；
- 测试矩阵、任务队列、阻塞台账、实验回执和主张证据矩阵。

## 禁止修改

- 三对角源码；
- 五对角消元公式、28 槽通信布局或未来 22 槽路径；
- persistent buffer、CUDA-aware、overlap 或其他性能优化；
- 通过放宽正常正确性阈值掩盖失败。

## 数值合同

- 算法仍为无主元交换 LU/缩约消元；不承诺一般非对角占优矩阵均可解。
- 在每个实际除法前，若 `abs(pivot) <= 64*epsilon(1.0d0)*row_scale`，则判定数值主元失效；`row_scale` 只由同一变换行的相关系数绝对值构造，因此整体行缩放不改变分类。
- 数值主元失效通过 `pascal_fail` 报告，错误码固定为 `4`；验证以非零进程退出码和 `numerical pivot breakdown` 消息双重确认。
- 正常/对角占优沿用 TASK-014 的 `1e-10` 解误差 Gate；弱占优和跨尺度同时要求相对残差、前向误差不高于 `1e-10`；受控近奇异族允许较大前向误差，但相对残差必须不高于 `1e-10`，并报告矩阵参数。

## 验证与停止条件

1. 独立 Node 脚本覆盖六类矩阵并验证尺度不变分类、残差和前向误差。
2. NVHPC + MPI 干净构建；`np=1/2` 的正常、弱占优、跨尺度、近奇异正例通过。
3. `np=1/2` 的零/近零主元用例均出现守卫消息并非零退出；不得以 NaN/Inf 作为预期失败。
4. 既有七项数学检查、API 回归和 TASK-014 正常 manufactured 回归不得退化。
5. 若尺度不变阈值误拒 TASK-014 正常输入，或需要改变消元/通信算法才能实现，则停止并保留证据，不把任务标为 `done`。

## 完成回执

- 独立 Node 六类矩阵全部通过；零/近零主元及其行缩放版本均分类为错误码 `4`。
- NVHPC 24.11 + OpenMPI 4.1.5 干净构建通过；专属 `np=1/2` 共 12 项、失败 0。
- 既有八项数学检查、容量模型自检、16 个 API 用例及 TASK-014 manufactured `np=1/2` 正常回归通过。
