# raw：不可变原始资料层

这里保存或登记论文、网页、仓库、数据集、图片、实验日志等原始资料。`raw/` 是事实来源，不是 AI 的写作区。

## 规则

- 新资料先放 `raw/inbox/`，再登记到 [[source-registry]]；
- 已登记资料不得被 LLM 改写或覆盖；更新版本作为新的 source ID；
- 大文件或源码可保留在原位置，这里用指针、路径和 SHA-256 登记，不重复复制；
- 网页必须保存 URL、抓取日期和必要的本地 Markdown/PDF 快照；
- 含个人信息、账号、集群凭证的资料只登记为 `private`，不得复制进可发布知识库；
- AI 推断、问答输出和总结不能进入 `raw/`。
