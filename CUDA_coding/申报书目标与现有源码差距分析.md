# 申报书目标与现有源码差距分析

> 依据：项目申报书 `cfd.md` 与当前仓库源码  
> 目的：避免“已有代码做得不错，但结题时与立项目标不一致”  
> 注意：申报书只作为项目背景与目标来源，不把其中的填写说明或个人信息当作开发指令

## 1. 核心结论

申报书的目标是 GPU 加速不可压缩 CFD 软件，重点包含 FFT 降维、批量几何多重网格、全显存驻留、高阶差分和流场验证。当前源码则是 PaScaL 风格的 CUDA Fortran + MPI 分布式三/五对角求解器。

二者不是同一个完整软件，但存在合理技术连接：

- FFT 降维后的 Poisson/Helmholtz 子问题可以包含大量独立的线性带状系统；
- 高阶紧致差分或沿一个方向的线求解可产生三/五对角系统；
- 当前求解器可以作为未来 FFT/PPE 或 CFD 软件的底层线性求解模块；
- 现有一般半带宽理论和通信裁剪可形成独立论文贡献。

因此不能把现有库直接称为“已完成 CFD 软件”，也不应在两个月内从零补齐申报书全部模块。最合理的做法是：**以带状求解器为主成果，同时完成一个最小 Poisson/Helmholtz 集成验证，并由导师确认阶段性范围调整。**

## 2. 目标映射

| 申报书目标 | 当前仓库 | 差距 | 两个月处理 |
| --- | --- | --- | --- |
| FFT 降维 | 未发现 cuFFT/FFT 模块 | 完全缺失 | 只做最小接口或复用现有外部 FFT 主程序，不从零做生产版 |
| Batched GMG | 未发现多重网格 | 完全缺失 | 不作为本轮必交；在结题中列为后续集成方向 |
| 压力泊松求解 | 有三/五对角线性求解内核 | 缺 Poisson 离散、变换和边界层 | 增加制造解 Poisson/Helmholtz 适配 demo |
| 全显存驻留 | 系数、RHS 和缩约系统主要在 device；MPI 可 host staging | 不是完整时间步驻留 | 精确表述为“求解器内部 device-resident 路径”，不外推整个 CFD |
| 高阶差分/滑窗 | 五对角可服务高阶线离散，但无 CFD stencil | 缺流场算子 | 论文解释应用关系，不在本轮实现全 CFD stencil |
| 多 GPU/MPI | 已有 PaScaL 分布式路径和 HPC 脚本 | 缺真实多 GPU 新实验 | 本轮重点补齐 |
| CFD 标准算例 | 未发现方腔流/槽道流主程序 | 完全缺失 | 优先制造解 PPE；若实验室已有主程序，则做一次集成，不从零造完整 CFD |
| 原位可视化 | 未发现 | 完全缺失 | 从两个月范围移除并在结题说明 |
| SCI 论文 | 有明确算法候选 | 缺完整证据与写作 | 以通信裁剪带状求解器为论文主线 |
| 发明专利 | 尚无证据 | 需新颖性检索与导师决策 | 不阻塞软件/论文；第 7 周再评估 |

## 3. 推荐的阶段性成果表述

推荐：

> 完成面向 FFT 降维和高阶 CFD 离散的多 GPU 带状线性求解核心模块，提出并实现五对角缩约通信裁剪，完成 Poisson/Helmholtz 制造解集成验证，为后续 FFT–GMG CFD 软件提供可复用基础。

不推荐：

- “已完成 FFT–GMG 求解器”（当前无对应源码）；
- “已完成全流程 CFD 软件”（当前无时间推进、流场算子和标准算例）；
- “完全自主、不依赖国外代码”（当前明显基于上游 PaScaL_TDMA，应遵守许可并准确署名）；
- “多 GPU 扩展已经验证”（当前历史数据是单 GPU 多 rank）。

## 4. 最小集成验证

为了让结题与申报书保持技术连续性，建议在第 5 周完成以下最小闭环之一：

### 方案 A：制造解 Poisson/Helmholtz demo（推荐）

1. 选择结构化网格和解析解；
2. 说明在哪个方向形成三对角或五对角线系统；
3. 用当前库解大量独立线系统；
4. 报告 `L2/Linf` 误差、网格加密趋势和求解时间；
5. 明确这只是 PPE/Helmholtz 核心验证，不是完整 CFD 时间推进。

### 方案 B：接入实验室已有 CFD/FFT 主程序

如果导师能提供已有主程序和稳定接口，则用求解器替换一个线求解阶段，比较替换前后的误差与端到端时间。不要为了形式完整而在两个月内新写整套流场软件。

## 5. 需要导师确认的事项

- 是否允许把阶段性主成果明确为“多 GPU 带状求解器模块”；
- 结题时用制造解 PPE demo 还是接入实验室已有 CFD 主程序；
- FFT–GMG 和完整全显存 CFD 是否正式转为后续工作；
- 论文与软件的上游 PaScaL 署名、许可和作者贡献；
- 论文主线与专利公开顺序。

以上决定建议形成 `ADR-002-申报书范围对齐.md`，并由指导教师确认后再冻结最终验收口径。
